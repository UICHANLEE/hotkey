# Stream Deck Style Macro Pad

브라우저에서 바로 실행되는 반응형 매크로 패드 UI입니다. 모바일 기기를 가로로 눕혀 쓰는 상황을 기준으로, 스트림 덱 느낌의 케이스, 픽셀 스크린, 버튼 눌림 모션, 키 조합 편집, 아이콘/이미지 커스터마이징, 프로필별 LocalStorage 저장을 포함합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다.

검증용 로컬 서버가 필요하면 아래 명령을 사용할 수 있습니다.

```sh
python3 -m http.server 4173
```

그 다음 `http://127.0.0.1:4173/index.html`로 접속합니다.

## 폰으로 Mac 조작하기

폰에서 누른 버튼을 Mac의 실제 키 입력으로 보내려면 브리지 서버를 실행합니다.

```sh
node server.js
```

터미널에 표시되는 `http://192.168.x.x:4173/` 형태의 주소를 폰에서 열고, 함께 표시되는 `Pair code`를 앱의 `Pair Code` 칸에 입력한 뒤 `Link`를 누릅니다. 이후 폰에서 버튼을 누르면 이 서버가 실행 중인 Mac에 키 입력이 전달됩니다.

macOS에서 처음 사용할 때는 터미널 또는 Node.js에 `시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용` 권한을 허용해야 합니다.

## 참고

일반 웹 브라우저는 보안 정책상 다른 데스크톱 앱으로 전역 단축키를 직접 전송할 수 없습니다. `server.js`는 같은 네트워크의 폰 브라우저 요청을 받아 Mac의 `osascript`로 키 입력을 발생시키는 로컬 브리지입니다.
