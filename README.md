# Stream Deck Style Macro Pad

브라우저에서 바로 실행되는 반응형 매크로 패드 UI입니다. 모바일 기기를 가로로 눕혀 쓰는 상황을 기준으로, 스트림 덱 느낌의 케이스, 픽셀 스크린, 버튼 눌림 모션, 키 조합 편집, 아이콘/이미지 커스터마이징, LocalStorage 저장을 포함합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다.

검증용 로컬 서버가 필요하면 아래 명령을 사용할 수 있습니다.

```sh
python3 -m http.server 4173
```

그 다음 `http://127.0.0.1:4173/index.html`로 접속합니다.

## 참고

일반 웹 브라우저는 보안 정책상 다른 데스크톱 앱으로 전역 단축키를 직접 전송할 수 없습니다. 이 앱은 버튼 클릭 시 페이지 내부 `KeyboardEvent`와 `macro-pad-shortcut` 커스텀 이벤트를 발생시키며, 실제 OS/편집 앱 제어가 필요하면 네이티브 래퍼나 로컬 브리지 서버가 필요합니다.
